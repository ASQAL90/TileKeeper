# TileKeeper 1.2.2

Rilis portabel Windows, tetap memakai .NET Framework 4.8 dan antarmuka bahasa Inggris.

## Perubahan pada rilis ini

- **X di title bar** kembali menyembunyikan jendela ke systray. `ShowInTaskbar` tidak diubah saat jendela dibuka; minimize dan close memanggil `Hide()`.
- Ukuran form **fixed**: tidak bisa di-resize atau dimaksimalkan.
- Daftar **Screen 1–4** diperpanjang sejajar grid map. Grid map tidak lagi menimpa checkbox **Borderless**.
- Tombol **About** dipindah ke kanan bawah tab **Display & Settings**. Grup **Process Protection** dan **Application Update** ditata ulang di bawah grup **Registry** dengan jarak 8 px agar tidak saling menumpuk.
- **Reset Programs & Layout** sekarang meminta konfirmasi (default **No**) dan mengembalikan seluruh `app.config` ke nilai awal secara permanen, termasuk cadangan di `%AppData%\TileKeeper\`.
- Checkbox **Enable** di daftar Arrange dan checkbox **ScreenN** langsung dipakai siklus berikutnya tanpa **Save & Close**.
- **Identitas baris stabil**: setiap program mendapat `ProgramId` persisten. `Screen1`–`Screen4` dan pin grid menyimpan ID, bukan komposisi nama/argumen yang bisa berubah saat duplikat ditambah/dihapus.
- **Remove** menghapus tepat satu ID. Baris saudara dengan nama/argumen sama tidak ikut terhapus dan tidak muncul sebagai duplikat baru.
- Dedup tetap berdasarkan **exe + argumen**, sehingga instance VNC/RDP dengan argumen berbeda tetap dibedakan.
- Konfigurasi lama dimigrasikan sekali saat aplikasi dibuka. Cadangan dibuat lebih dulu sebelum migrasi.
- Mengurangi kedip saat membuka jendela dari tray: `Screen.AllScreens` di-cache, penulisan config dilakukan sekali, dan rebuild daftar dibungkus penekanan repaint.

## Perbaikan alur Keep Running ↔ Arrange

- Menambah program di **Keep Running** sekarang otomatis menambahkan baris pasangannya di **Arrange**. **Arrange menjadi satu-satunya sumber** untuk checklist Screen 1–4.
- **Remove di Keep Running** hanya menghapus baris peluncuran; baris Arrange beserta assignment Screen 1–4 tetap ada.
- **Remove di Arrange** menghapus assignment Screen 1–4 milik baris itu, tetapi **tidak** menghapus baris Keep Running.
- **Uncheck Enable di Arrange** mengecualikan program dari auto arrange/reposition. Program tersebut tidak dipindah atau di-resize dan bisa diatur manual; sel miliknya tetap kosong dan tidak ditempati program lain (contoh 4 program pada grid 2×2 dengan satu di-uncheck → tetap 2×2, 3 petak terisi, 1 kosong, tanpa stretch).
- Assignment lama yang masih memakai ID Keep Running otomatis diarahkan ke ID Arrange pasangannya saat pertama kali dibuka, sehingga switch Enable di Arrange yang berlaku.
- Mirror Keep Running → Arrange hanya di-seed **sekali** (`PositionMirrorSeeded`). Baris Arrange yang sengaja dihapus tidak dibuat ulang saat aplikasi dibuka lagi.
- **Restore dari tray** cukup satu double-click: jendela langsung tampil di depan dan tidak langsung tersembunyi lagi oleh transisi minimize.

## Perbaikan dari uji Windows paket sebelumnya

- **Restore tray menampilkan jendela penuh sekali jalan**: `X` kini hanya memanggil `Hide()` — tidak menyetel `WindowState = Minimized` lalu menimpa `Size`. Urutan itulah yang merusak rect restore Windows sehingga jendela muncul hanya sebagai title bar, perlu double-click kedua, lalu berkedip dan menetap di pojok kiri bawah. Ukuran asli diambil sekali sebelum minimize pertama dan dipakai ulang saat restore.
- **Restore tray tidak lagi melompat/berkedip**: posisi dihitung sebelum jendela ditampilkan, lalu `Show()` dan `SetForegroundWindow`. Pemanggilan `BringToFront`/`Activate` yang memicu redraw berulang dihapus.
- **Watchdog** mengenali aplikasi yang sudah berjalan sebelum TileKeeper dijalankan. Command line yang tidak terbaca (WMI dingin, process elevated/protected) dianggap **hidup**, bukan mati. Proses hasil launch diadopsi berdasarkan PID, dan relaunch dibatasi per target, sehingga aplikasi tidak dijalankan berulang tiap siklus.
- **Relaunch ClickOnce**: peluncur `rundll32 dfshim.dll` keluar segera setelah menyerahkan deployment ke aplikasi. Peluncur itu tidak lagi dicatat sebagai target; watchdog menunggu sampai 30 detik dan mengadopsi proses aplikasi yang sebenarnya. Bila deployment masih berjalan setelah itu, jendela launch diperpanjang 180 detik agar aplikasi tidak dibuka berulang-ulang.
- **Placeholder grid**: baris Arrange yang di-uncheck tetap menempati selnya sebagai placeholder kosong. Grid 2×2 tidak berubah menjadi 1×2 dan aplikasi lain tidak stretch mengisi baris kosong. Kini preview grid ikut berubah: sel baris yang di-uncheck langsung tampil kosong.
- **Jumlah sel grid = jumlah baris tercentang**: bila urutan klik kehilangan sebuah baris (mis. setelah reload config), baris yang tercentang tetap ditambahkan ke urutan sehingga grid tidak lagi menampilkan 3 sel untuk 4 baris tercentang.
- **Klik checklist Screen 1–4 tidak berkedip lagi**: hanya screen sumber (dan screen yang berubah karena dedup) yang digambar ulang; seluruh tab Arrange tidak lagi di-suspend/di-repaint per klik. Perubahan Rows/Cols juga hanya me-refresh screen pemiliknya.
- **Klik grid map langsung mengubah posisi**: mengganti pin cell (misal cell 1 dari aplikasi A ke B) kini langsung diterbitkan ke worker positioning dan siklus berikutnya segera memakainya. Sebelumnya perubahan hanya masuk `app.config` saat **Save & Close**, sehingga baru terasa setelah TileKeeper ditutup dari tray dan dibuka lagi. Save juga ikut menerbitkan ulang plan layar.
- **Rows/Cols 1–3 (hybrid)**: textbox disempitkan dan rata tengah, hanya menerima digit `1`–`3`. Tombol `-`/`+` menaikkan/menurunkan nilai tanpa bisa keluar dari 1–3. Config lama yang masih berisi `0` dinormalisasi ke `1` saat dimuat. Jika jumlah aplikasi tercentang melebihi kapasitas grid, TileKeeper otomatis menaikkan Rows/Cols ke ukuran minimal yang muat (maks 3×3) dan memperbarui field, sehingga tidak ada dua aplikasi yang jatuh ke cell yang sama. Clear/uncheck tidak mengecilkan matrix (FR-01).
- **Grid bisa disusun sebelum ada aplikasi**: jika Rows/Cols diisi tetapi checklist Screen kosong, grid tetap tampil dengan sel **abu-abu** dan bisa diklik. Memilih aplikasi dari daftar Screen pada cell itu otomatis men-centang barisnya dan mengunci aplikasi ke cell tersebut. Sel yang tidak di-assign tetap kosong dan tidak diisi/stretch oleh aplikasi lain.
- **Nomor cell tidak bergeser saat baris di-uncheck**: pin dikunci **sebelum** status checklist berubah, dari layout yang masih sama seperti yang terlihat user (event `ItemCheck` terjadi sebelum kontrol menyimpan status baru). Membekukan setelah perubahan — seperti versi sebelumnya — mengunci layout yang sudah reflow sehingga baris nomor 4 ikut bergeser. Kini uncheck baris nomor 3 menyisakan cell 3 kosong; baris nomor 4 tetap di cell 4. Pin baris yang di-uncheck tidak dibuang, jadi men-centangnya lagi mengembalikannya ke cell semula. **Save & Close** menyimpan pin untuk semua baris, termasuk yang sedang tidak tercentang.
- **Screen tanpa monitor menjadi inert**: checklist Screen, checkbox AutoFit/Borderless, field Rows/Cols beserta tombol `-`/`+`, dan grid map semuanya di-disable bila monitor ke-N tidak terdeteksi. Baris dan pinnya tetap tersimpan; menyambung monitor kembali mengembalikan seluruh tata letak tanpa perlu mengisi ulang.
- **Menu "Clear this cell (leave empty)"**: klik nomor cell → pilih opsi ini untuk mengosongkan cell. Aplikasi yang pernah memakainya di-uncheck dari screen tersebut (barisnya tetap ada di daftar), pin ke cell itu dihapus, dan cell dicatat sebagai **reserved empty cell**. Bentuk matriks tetap sama (2×2 tidak menyusut jadi 2×1/1×2), cell lain tetap bernomor sama, dan setelah **Save & Close** / buka ulang cell itu tetap kosong. Memilih aplikasi lagi ke cell yang sama menghapus reservasi tersebut.
- **Peringatan konfigurasi belum disimpan**: klik **X** atau menyembunyikan jendela ke systray sekarang memunculkan dialog **Save / Don't Save / Cancel** bila ada perubahan yang belum lewat **Save & Close**. **Yes** menyimpan lalu tetap masuk tray, **No** **membuang** perubahan belum tersimpan dan memuat ulang config tersimpan terakhir (UI dan live plan worker ikut kembali), **Cancel** membatalkan dan jendela tetap terbuka. Deteksi membandingkan semua nilai yang ditulis Save terhadap snapshot terakhir, sehingga refresh internal tidak memicu popup. Save yang berhasil atau penghapusan baris yang langsung ditulis ke config tidak dianggap "belum disimpan".
- **Klik checkbox tidak lagi massal**: klik checkbox di daftar **Keep Running** / **Arrange** hanya mengubah baris yang diklik, meski ada beberapa baris yang sedang dipilih untuk Remove massal. Handler hanya mengintersep hit-test pada glyph checkbox (`StateImage`). Drag-select multi-baris (mouse down di luar checkbox, lalu drag/release/hold) hanya mengubah seleksi; `ItemCheck` dibatalkan selama drag-select aktif sehingga checkbox tidak berubah saat mouse up. Remove massal tetap bekerja dari seleksi.
- **Assign ke reserved-empty cell**: setelah **Clear this cell (leave empty)**, mencentang/mengassign aplikasi dari daftar Screen di samping akan mengisi cell reserved-empty dengan **indeks terkecil** terlebih dulu, bukan cell auto-fill terakhir. Reservasi cell dikonsumsi saat diassign agar tidak ada duplikat nomor cell.
- **Capture resolusi** membaca **piksel fisik** dari display driver (mis. 1920×1200 pada scaling 125%), bukan `Screen.Bounds` yang mengembalikan DIP (1536×960). Status menampilkan `Captured … (physical pixels)`.
- **Display & Settings**: grup **Process Protection** dan **Application Update** tidak lagi bertumpuk setelah About dipindah; jarak antar segmen konsisten 8 px.

## Migrasi konfigurasi

Kunci baru di `app.config`:

- `ProgramId` — ID persisten per baris program/position-only.
- `PositionProgramId` — ID persisten yang dipakai daftar Arrange.
- `ScreenIdsMigrated` — penanda migrasi sekali jalan.
- `PositionMirrorSeeded` — penanda bahwa mirror Keep Running → Arrange sudah dijalankan sekali.
- `Screen1SlotPins`–`Screen4SlotPins` — pin `id=cell` untuk semua baris, termasuk yang sedang tidak tercentang, agar nomor cell stabil setelah uncheck dan reload.
- `Screen1ReservedCells`–`Screen4ReservedCells` — indeks cell (CSV, zero-based) yang sengaja dikosongkan lewat **Clear this cell (leave empty)** agar bentuk matriks tetap utuh setelah Save/reload.

Config tanpa kunci tersebut masih diterima. Nilai `Screen1`–`Screen4` yang berupa nama lama dipetakan ke ID saat migrasi. File cadangan disimpan sebelum penulisan.

## Dukungan file saat ini

Dialog **Add…** memfilter `.lnk`, `.appref-ms`, `.rdp`, `.vnc`, dan `.exe` (plus **All Files**). Resolver saat ini:

| Ekstensi | Perilaku |
|---|---|
| `.lnk` | Target shortcut + argumen dibaca; shortcut ClickOnce diubah ke perintah `rundll32 dfshim.dll,...`. |
| `.appref-ms` | URL deployment ClickOnce diambil dari isi file. |
| `.rdp` | Disimpan sebagai `mstsc.exe "path\file.rdp"`, sehingga tiap koneksi punya identitas argumen sendiri. |
| `.vnc` | Perintah buka dari asosiasi file Windows dibaca dari registry, `%1` diganti path file. |
| `.exe` | Dipakai langsung sebagai program. |
| Lainnya | Saat ini hanya menjadi nama + folder. File teks/dokumen/gambar/video **belum** menjadi target yang bisa dijalankan ulang atau ditata. |

Rencana perluasan ekstensi dan batasannya ada di [`SUPPORTED-FILES.md`](../SUPPORTED-FILES.md).

## Yang belum berubah

- Grid tetap maksimal **3×3 per monitor**, maksimal **4 monitor**.
- Satu process hanya menghasilkan **satu target window** (`MainWindowHandle` atau window terbesar saat **Match Largest Window** aktif). Belum ada aturan per judul/class/HWND.
- Window UWP/cloaked, child window, tab di dalam browser, dan window elevated dari process non-elevated masih menjadi batasan.
- DACL process protection, mutex single-instance, dan pencocokan argumen RDP/VNC dipertahankan.

## Checklist uji Windows

1. Klik **X** → jendela hilang, ikon tetap di tray; klik kanan → **Show** muncul tanpa reload.
2. Coba resize/maksimalkan → ukuran tidak berubah.
3. Tab **Arrange Windows** → checklist Screen 1 tidak tertimpa grid; checkbox **Borderless** masih bisa diklik.
4. Tab **Display & Settings** → **About** di kanan bawah; grup Registry, Process Protection, dan Application Update tersusun rapat tanpa tumpang tindih.
5. **Reset Programs & Layout** → muncul peringatan; pilih **No** → tidak ada perubahan.
6. Tambah dua shortcut ke exe sama dengan argumen beda → dua baris; Remove salah satu → saudara tetap ada dan tidak muncul duplikat.
7. Centang/uncheck **Screen1** dan **Enable** tanpa Save → siklus positioning berikutnya mengikuti.
8. Tambah program baru di **Keep Running** → baris pasangannya langsung muncul di **Arrange** tanpa restart.
9. Uncheck **Enable** pada baris Arrange → preview grid langsung mengosongkan selnya, program berhenti dipindah/di-resize pada siklus berikutnya dan bisa diatur manual; program lain tidak stretch. Centang lagi → kembali ditata.
10. Centang 4 program di checklist Screen 1 → grid menampilkan 4 sel bernomor (bukan 3); klik beberapa baris berturut-turut → daftar dan grid tidak berkedip. Klik cell grid map lalu pilih aplikasi lain → siklus positioning berikutnya langsung memakai cell baru tanpa restart; **Save & Close** juga menyimpan pin yang sama.
11. Kosongkan semua checklist Screen 1, isi Rows=2 dan Cols=2 (tombol -/+ tidak bisa melewati 3, textbox rata tengah) → 4 sel abu-abu tampil; klik sel 3 lalu pilih aplikasi dari daftar Screen 1 → baris tercentang dan aplikasi menempati cell 3, tiga cell lain tetap kosong.
12. Coba ketik `0`, `4`, `-1`, atau huruf pada Rows/Cols → tidak diterima; paste `9` → otomatis menjadi `3`; `-` pada `1` tetap `1`.
13. **Remove** baris di Keep Running → baris Arrange dan assignment Screen 1–4 tetap ada.
14. **Remove** baris di Arrange → assignment Screen 1–4 hilang, tetapi baris Keep Running tetap ada.
15. Restore dari tray dengan **satu** double-click → jendela langsung tampil di depan.
16. Tutup aplikasi, buka lagi → ID, checklist screen, dan pin grid tetap terbaca; baris Arrange yang sudah dihapus tidak muncul kembali; cadangan config dibuat saat migrasi pertama.
17. Jalankan beberapa aplikasi lebih dulu, lalu start TileKeeper → aplikasi yang sudah berjalan tidak dijalankan ulang pada siklus-siklus berikutnya; CPU/memory tetap stabil.
18. Tutup salah satu aplikasi yang dipantau → TileKeeper menjalankannya tepat satu kali (tidak beruntun).
19. Tambahkan aplikasi **ClickOnce** (`.appref-ms`/shortcut deployment), jalankan, lalu tutup dan buka TileKeeper → aplikasi tidak diluncurkan ulang berulang; `rundll32` yang keluar setelah hand-off tidak dianggap target mati.
20. Set scaling Windows 125% pada layar 1920×1200 → **Capture** menampilkan `1920 x 1200 (physical pixels)`; Save & Close tidak mengubah resolusi monitor.
21. Buka dari tray (double-click ikon) → jendela muncul di tengah layar tanpa melompat dari pojok dan tanpa redraw berulang.
22. Tutup dengan **X**, lalu buka lagi dari tray → jendela langsung tampil penuh di tengah, bukan hanya title bar; tidak perlu double-click kedua dan tidak berkedip di pojok kiri bawah.
23. Grid 2×2 dengan 4 aplikasi tercentang → uncheck aplikasi nomor 3 → cell 3 kosong, aplikasi nomor 4 tetap di cell 4. Centang lagi aplikasi nomor 3 → kembali ke cell 3. **Save & Close**, buka ulang → nomor masih sama.
24. Klik cell yang terisi → pilih **Clear this cell (leave empty)** → cell tersebut kosong, baris aplikasinya tetap ada di daftar Screen (tidak tercentang), cell lain tidak bergeser.
25. Ubah salah satu field/centangan tanpa Save, lalu klik **X** → muncul dialog **Unsaved changes** dengan default **Cancel**. Pilih **Cancel** → jendela tetap terbuka; **No** → masuk tray, buka lagi dari tray menunjukkan nilai kembali ke config tersimpan terakhir (perubahan dibuang); **Yes** → tersimpan dan tidak muncul popup lagi saat X berikutnya.
26. Klik **Save & Close** lalu buka lagi dari tray → tidak ada popup "unsaved" meski jendela baru saja ditutup. Hapus baris di **Arrange** (yang langsung menulis config) lalu klik **X** → juga tidak ada popup.
27. Putuskan monitor ke-3/ke-4 (atau set konfigurasi hanya 2 monitor) → checklist Screen 3/4 abu-abu dan tidak bisa dicentang; field Rows/Cols, tombol `-`/`+`, AutoFit/Borderless, dan grid map juga tidak merespons klik. Pasang kembali monitor → checkbox, pin, dan cell lama kembali persis seperti sebelumnya.
28. Grid 2×2 dengan 4 aplikasi (Rows=2, Cols=2) → uncheck baris nomor 2 → tetap 2×2, cell 2 kosong, baris 1/3/4 masing-masing di cell 1/3/4. Ulangi uncheck baris nomor 3 → tetap 2×2 dengan dua cell kosong; jangan sampai berubah menjadi 2×1 atau 1×2. Centang lagi baris yang di-uncheck → kembali ke cell semula.
29. Grid 2×2, klik cell 2 → **Clear this cell (leave empty)** → tetap 2×2, cell 2 kosong, cell 1/3/4 tidak bergeser. **Save & Close**, buka ulang → bentuk dan cell kosong tetap sama. Klik cell 2 lagi lalu pilih aplikasi → cell terisi kembali.
30. Drag 3 file ke daftar **Keep Running** atau **Arrange** → klik checkbox satu baris → hanya baris itu yang berubah. Drag-select/blok beberapa baris (bukan klik glyph checkbox) lalu lepas mouse / tahan / release → checkbox baris-baris tersebut **tidak berubah**; seleksi tetap bisa dipakai untuk **Remove** massal. Klik checkbox satu baris saat beberapa baris terpilih → hanya baris itu yang berubah.
31. Ubah checkbox/pin/Rows/Cols tanpa Save → klik **X** → **No** → buka lagi dari tray → kembali ke nilai tersimpan terakhir; worker tidak terus memakai layout yang dibatalkan. **Cancel** tetap membuka jendela; **Yes** menyimpan.
32. Field Rows/Cols: `0`, `4`, `-1`, huruf, dan paste nilai di luar 1–3 ditolak/diclamp ke 1..3. Config lama berisi `0` terbaca sebagai `1`. Jika jumlah aplikasi tercentang melebihi kapasitas grid manual, grid auto-grow ke ukuran minimal yang muat (maks 3×3) dan field Rows/Cols ikut diperbarui; tidak ada dua aplikasi di cell yang sama.
33. DPI 100%/125%/150% pada resolusi fisik yang sama → **Capture** tetap menampilkan piksel fisik `(physical pixels)` (regresi).
34. Grid 2×2, klik cell 1 → **Clear this cell (leave empty)**, lalu cell 3 → **Clear this cell (leave empty)**. Centang/assign aplikasi dari daftar Screen di samping → aplikasi masuk ke cell reserved-empty **indeks terkecil** (cell 1 dulu, lalu cell 3). Tidak ada dua baris yang mendapat nomor cell sama; cell lain tidak bergeser.
