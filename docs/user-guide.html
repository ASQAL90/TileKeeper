Beginner's guide

Getting the most out of TileKeeper

TileKeeper keeps the programs you rely on open, running, and sitting in the right place on your screens — automatically. This guide walks through every screen in plain language, assuming you've never opened the settings window before.

02 Five-minute quick start

If you only want the shortest path to a working setup, follow these steps in order. You can read the detailed explanations below afterward.

  1. Start TileKeeper

    Open TileKeeper.exe. Look near the Windows clock for its tray icon.

  2. Open the settings

    Right-click the tray icon and choose Show.

  3. Add one program

    On Programs, click Add... and select the program shortcut or executable you want TileKeeper to watch.

  4. Choose automatic restart

    Check Enable Keep Running. Leave the cycle at about 20 seconds for your first test.

  5. Choose the destination

    Open Position, check the program under the monitor where you want it to appear, and leave AutoFit checked.

  6. Save and test

    Click Save. Close the watched program, wait for the cycle, and confirm that TileKeeper starts it again.

Success

You have completed the basic setup when the program relaunches and returns to the chosen monitor. Add more programs or change the grid only after this first test works.

03 How the automatic checks work

TileKeeper works quietly in the background. It does not replace Windows or control every application; it only acts on entries you configure.

Keep Running

Checks whether each program-list entry is running. If it is closed, TileKeeper launches that entry again.

Position

Looks for the matching window and moves it to the screen and grid cell you selected.

  1. Wait for the cycle

    The cycle value is measured in seconds. A value of 20 means TileKeeper checks approximately every 20 seconds.

  2. Identify the entry

    Each configured item is tracked separately. Two shortcuts to the same executable can represent different connections when their arguments differ.

  3. Apply the rule

    A closed program may be launched; an open matching window may be moved or resized when custom positioning is enabled.

Important

TileKeeper cannot repair a broken shortcut, missing executable, blocked network connection, or application crash caused by the application itself. It can try to launch the configured entry again.

04 A setup style that works for everyone

TileKeeper can be used for control rooms, remote support, home offices, classrooms, accessibility setups, and any workspace where windows should return to predictable places.

01 What this program does

Think of it as a caretaker for your other programs. You tell it which programs matter (a SCADA viewer, a VNC session, a monitoring app — anything with an .exe), and it does two jobs for you in the background, all day, without you touching it:

  • Keep Running — if one of those programs closes or crashes, it gets relaunched automatically, on a timer you choose.
  • Position — each program's window gets moved back to the monitor and screen area you assigned it, even if someone drags it out of place.

Everything is configured from one settings window, split into three tabs: Programs, Position, and System.

02 Finding it in the system tray

TileKeeper doesn't live on your taskbar. Once it's running, it sits quietly in the system tray (the small icons near your clock, bottom-right of the screen).

  1. Find the icon

    Look in the system tray. If you don't see it, click the small ^ arrow to show hidden tray icons.

  2. Right-click it

    A small menu appears with two options: Show and Exit.

  3. Click Show

    The settings window opens. Whatever changes you made previously are already loaded in.

Note

Closing the settings window with the X button does not stop the program — it just minimizes back to the tray, so Keep Running and Position keep working. To fully stop the program, use Exit from the tray menu — this build has no exit password, so Exit stops the program immediately.

  2. Pick the program

    Choose a desktop shortcut, a ClickOnce application, a Remote Desktop file, a VNC connection file, or the program's .exe directly. You can select several at once. A .vnc file launches through whichever VNC viewer Windows already has associated with that extension — no extra setup needed.

  • Up / Down — move the selected row. Order matters when several unpinned programs share a screen (see Pinning to a grid cell).
Tip

You can't accidentally add TileKeeper itself to this list — the app blocks that, since watching and repositioning itself would cause problems.

05 Keep Running

At the top of the Programs tab is a checkbox: Enable Keep Running, with a Cycle (seconds) field next to it.

  • When checked, the app checks every program in your list on a timer.
  • If a program isn't running, it launches it again automatically.
  • Cycle (seconds) sets how often that check happens — a lower number reacts faster but checks more often; 15–30 seconds is a reasonable default.
Good to know

This only relaunches a program that's completely closed. It never interferes with a program that's still open and running — even if its window is minimized or hidden.

06 Same program, different arguments

A common case: you connect to several remote computers using the same viewer program, just with a different address each time — two VNC sessions, or two instances of a plant floor tool pointed at different equipment. TileKeeper treats each of these as its own, separately tracked entry.

Program

If you close only the ...A window, Keep Running relaunches only that one — the still-open ...B window is left alone. The Position tab shows both as separate, clearly labeled entries too, so you can send each to a different screen.

07 Programs to Position

Open the Position tab. Near the top is its own small list, titled Programs to Position (added here are not launched by Keep Running)—a second way to add a program, used only for window placement.

When to use this

Use the Programs tab's list for anything you want auto-relaunched. Use this Position-only list for something you always start by hand, but still want positioned correctly once it's open — it never gets launched or restarted by this app.

It has the same Add / Edit / Remove / Up / Down buttons as the Programs tab. Every program you add — from either list — becomes available to check off in the four screen lists below it.

Checkbox

Each row's checkbox is the Match Largest Window flag (see below), not a row selector. Checking it also selects the row (highlighted), so Edit/Remove/Up/Down apply to it right away without an extra click. Unchecking a row leaves the current selection alone.

08 Assigning screens

Below the program lists are four boxes: Screen 1 through Screen 4, one per physical monitor. When a screen's monitor isn't currently connected, only its Rows/Cols/AutoFit/grid preview gray out — plug the monitor in and those light up on their own, no restart needed. The program checklist itself always stays clickable, even for a disconnected screen, so you can check, uncheck, or reassign a program off it at any time without needing that monitor plugged in.

Each checked row shows the number and fill colour of the grid cell it landed in.
  • Check a program's box to assign it to that screen.
  • Checked rows carry a number badge — (1), (2), … — and fill with their grid-cell colour, so the checklist tracks the grid preview exactly. Numbers follow the order you check the boxes (click order), not the list order: the first program checked takes cell 1, the next cell 2, and so on.
  • A program can only be checked on one screen at a time — checking it here grays it out on the other three.
  • Rows / Cols set the tiling grid for that screen (leave at 0 for automatic sizing based on how many programs are checked).
  • AutoFit — when checked, every window on that screen is resized to fill its tile. When unchecked, windows keep their own size and are just moved into position.
  • Borderless — checked (the default) runs that screen's windows without a title bar or border, edge-to-edge across their tiles. Unchecking switches that screen to border mode (below).

Border mode (Borderless unchecked)

Windows keep a title bar and a thin frame but stay flush to their tile — no overlap onto the neighbor, no desktop gap between windows. The change is instant: untick and the windows re-frame on the next scan tick.

  • The Windows drop shadow is suppressed in this mode, so no dark translucent strip appears between adjacent windows.
  • Adding a title bar takes ~30 px out of the window's client area. Apps that stretch their canvas to the window (typical SCADA/overview screens) rebuild their content into the smaller client automatically and are unaffected. Apps that draw at a fixed canvas size will have their bottom content cut off in border mode — for those, leave Borderless checked instead (or make the app scale its canvas to the client size).

09 Pinning to a grid cell

By default, checked programs fill the grid in the order you check them. If you want a specific program to always land in a specific spot, click directly on that cell in the grid preview.

  1. Click a grid cell

    A small menu pops up listing every program checked for that screen, plus an Auto-fill (clear pin) option.

  2. Pick a program

    That program is now pinned to this exact cell every time the layout is applied, and its checklist badge number and row fill update to match the pinned cell.

Un-pinning

Auto-fill (clear pin) removes the manual pin; the program then takes the next free cell in click order like any other checked program.

Limit

A grid can go up to 3 × 3 (nine cells) per screen. Saving with more checked programs than cells is rejected with an explanation.

10 Match Largest Window

Some programs open more than one window — a small toolbar, a splash screen, a floating panel — alongside their real, main window. Normally TileKeeper guesses which window is the "main" one using the same signal Windows itself uses. For most programs, that guess is right every time.

If you notice a small companion window getting moved or resized instead of the program's real window, check the box next to that program's row in the Programs to Position list. This tells TileKeeper to always pick that program's largest currently visible window — almost always the one you actually want moved.

Default

Leave this unchecked unless you actually see the wrong window being repositioned. It's off by default for every program.

11 Display resolution hold

Also on the System tab. Some displays report a resolution larger than what a room actually needs, which can push windows off-screen. This section can clamp the display back down to a fixed size on a timer.

  • Hold display resolution — turns the clamp on or off.
  • Width / Height — the resolution to hold.
  • Capture current — fills Width/Height with whatever your display is set to right now, so you don't have to look it up.
  • Check (sec) — how often to re-apply it.

14 Full walkthrough example

Putting it together: two VNC connections to different equipment computers, kept running, and tiled side by side on your second monitor.

  1. Create two shortcuts

    In Windows, right-click your VNC viewer's .exe and choose Create shortcut, once for each computer. Edit each shortcut's properties so its Target ends with that computer's address, e.g. tvnviewer.exe 192.0.2.10:5900.

  2. Add both to the Programs tab

    Click Add..., select both shortcuts at once. They appear as two separate rows, each ending in a different address.

  3. Turn on Keep Running

    Check Enable Keep Running. Closing either connection now brings back only that one.

  4. Assign them to Screen 2

    On the Position tab, check both programs under Screen 2. Set Cols to 2 so they sit side by side, and check AutoFit so each fills half the screen.

  5. Enable positioning and save

    Check Enable Custom Position, then click Save at the bottom of the window.

From now on, both connections launch automatically, relaunch individually if either drops, and snap back into their half of Screen 2 if someone drags a window out of place.

15 Troubleshooting

SymptomWhat to check
A program never launches Check Enable Keep Running is checked, and that its row's path still points to a file that exists.
Closing one of two similar entries relaunches the wrong one Make sure each shortcut's arguments are actually different — two shortcuts with identical arguments are treated as the same entry.
A window won't move to its assigned screen Confirm Enable Custom Position is checked and you clicked Save. Try Match Largest Window if a small companion window is being moved instead (see above).
Screen 3 or 4's Rows/Cols/grid look grayed out That monitor isn't currently detected — connect it and those controls re-enable immediately. The checklist itself stays usable either way; you can still check, uncheck, or reassign a program on a disconnected screen and Save persists it normally.
Saving is rejected with a grid-size error You've checked more programs for a screen than its grid has cells. Either increase Rows/Cols, or uncheck a program.
Bottom strip of a window's content is cut off in border mode That app draws at a fixed canvas size and doesn't stretch into the smaller client a title bar leaves behind. Check Borderless for that screen, or make the app scale its canvas to the client size.
Exit asks for a password You're running the wrong build — this variant has no exit password and stops immediately from the tray Exit item.
The configuration file was deleted or is missing The app recreates it automatically the next time it's launched. It restarts itself once so the new file takes effect — you may briefly see the tray icon appear twice — then starts normally with default settings.
